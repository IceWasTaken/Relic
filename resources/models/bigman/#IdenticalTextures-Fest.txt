The Splatfest models share some textures with the regular model. In order 
to reduce the file size and keep things nice and tidy, identical textures 
are stored in the main directory.

If you're not too keen on identifying each individual shared texture:

1. Copy all textures from main folder.

2. Paste copied textures into Splatfest folder.

3. When prompted on replacing existing files, select "Don't copy" or "No".

Shared textures are now copied over, while any textures that are unique 
to Splatfests yet use the same texture names are not accidently replaced.
						      ~ Centrixe the Dodo
